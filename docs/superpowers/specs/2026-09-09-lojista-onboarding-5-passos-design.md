# Onboarding 5 passos do lojista (v2)

**Date:** 2026-09-09  
**Status:** Locked — Marketing + Mauricio  
**Repo:** voltou-front (front-only)

## Goal

Primeiro acesso = entender o que a Voltou faz + próximo passo. Zero ruído. Dashboard completo só em **5/5**.

## Top copy (exata, H1)

```
A 1ª venda você fez no balcão.
A 2ª venda a Voltou faz por você.
```

Nada acima dessas duas linhas. **"Deixe a loja pronta"** não é o H1 — só rótulo da checklist, abaixo de **"X de 5 prontos"**.

## Ordem vertical

1. Duas linhas-mãe
2. Progresso `X de 5 prontos` (número grande `#0e9254`)
3. Rótulo opcional `Deixe a loja pronta`
4. Lista vertical de 5 (○ / ✓ + nome curto + chevron)
5. Empty do próximo passo: 1 frase + 1 CTA verde

## Tarefas (ordem dura)

1. Cliente (nome + número)
2. Produto (1 peça)
3. Regras — teto de desconto + essenciais
4. Mercado Pago
5. Endereço de retirada + WhatsApp de aviso de pedido

WhatsApp da loja no Perfil continua **opcional** e não entra no checklist.

## Dashboard

Hard gate: tela cheia (Olá, PDF, recuperados, De/Até, gráficos, lista) **só em 5/5**. Até lá a rota Dashboard é a setup. Em 5/5: checklist some ou `Loja pronta ✓` dismissível uma vez.

## Empty states (exatos)

1. Cadastre o 1º cliente — nome e número de quem comprou ou teve interesse. / Cadastrar cliente
2. Cadastre 1 produto que já está na arara. / Cadastrar produto
3. Defina o teto de desconto da loja — a Voltou usa isso na 2ª venda. / Definir regras
4. Conecte o Mercado Pago pra receber quando a venda fechar. / Conectar Mercado Pago
5. Informe o endereço de retirada e o WhatsApp de aviso de pedido. / Cadastrar retirada

Rótulo opcional acima do empty: `Próximo passo` + `X de 5`.

## Visual

- Cores: `#0e9254` / `#111e15` / `#f6fbf6`
- CTA único: `#0e9254`, largura quase total (16px), altura ~52–56px, texto `#f6fbf6`
- Item atual: fundo `#f6fbf6`, borda verde, bold
- Feitos: ✓ clicável para editar (outline `#111e15`)
- Futuros: neutros
- Mobile-first ~360–390, toque ≥44px, uma coluna
- Header: logo + avatar. Nav inferior ok.
